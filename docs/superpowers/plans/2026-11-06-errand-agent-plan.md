# Errand Agent Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Every task is red → green → refactor → commit.

**Goal:** Local chat agent that books/cancels/reschedules home services against mocked tools, with app-enforced approval, idempotent recovery, persistent memory, traces, and ≥20 offline evals.

**Architecture:** Deterministic Python shell (state machine, approvals, executor, recovery, context builder) around a model that only reads and *requests* actions. SQLite for agent state; in-process mock tool environment with seeded RNG and scripted outcomes.

**Tech Stack:** Python 3.13 stdlib (sqlite3, urllib, json, hashlib), pytest. No other runtime deps.

## Global Constraints
- Tool names/inputs/outputs/failure behaviours exactly as PDF §2.
- No side effect without a granted, unconsumed approval whose digest matches the exact action.
- Evals and tests run offline (ScriptedModel). Live chat uses `XAI_API_KEY`.
- Never invent metrics; eval table generated by the run.
- Deadline: Sun 2026-11-09 23:59 IST.
